
# PrimeMart – E-commerce Mobile App

PrimeMart is a modern e-commerce mobile application built with React Native (Expo). It allows users to browse products, add items to cart, place orders, and make secure payments.




## Features

🔐 User Authentication (Sign up / Login)

🛒 Add to Cart & Manage Cart

📦 Order Management

💳 Secure Payments with Stripe

🔍 Product Browsing & Search

❤️ Wishlist (Favorites)

📱 Clean and Responsive UI


## Tech Stack
Frontend: React Native (Expo)

Backend / Database: Supabase

Authentication: Supabase Auth

Payments: Stripe

Products API: Fake Store API

Navigation: Expo Router

State Management: (Redux / Context – update if needed)


📦 API Integration
🛍️ Products

Products are fetched from:

https://fakestoreapi.com/

🔐 Authentication & Orders

Handled using Supabase:

User authentication (email & password)

Order storage and retrieval

💳 Payments

Handled using Stripe:

Secure checkout

Payment intent integration
